# 🐳 docker-learning

Repositorio de aprendizaje de **Docker** para el curso de **Data Engineering 2026**.

Cada módulo es un proyecto independiente y autocontenido, con ejercicios guiados y un entorno listo para levantar.

---

## 📚 Módulos

### Módulo 1: PostgreSQL

Aprendé volúmenes, puertos, redes y comandos básicos usando una base de datos PostgreSQL real con interfaz web (pgAdmin).

➡️ [Ver módulo PostgreSQL](./postgresql/README.md)

| Ejercicio | Concepto |
|---|---|
| [01 - Volúmenes](./postgresql/ejercicios/01_volumenes.md) | Persistencia de datos |
| [02 - Puertos](./postgresql/ejercicios/02_puertos.md) | Exposición de servicios |
| [03 - Comandos](./postgresql/ejercicios/03_comandos.md) | Ciclo de vida de contenedores |
| [04 - Redes](./postgresql/ejercicios/04_redes.md) | Comunicación entre contenedores |

---
